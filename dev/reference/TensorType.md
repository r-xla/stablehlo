# TensorType

Represents a tensor type with a specific data type and shape.

## Usage

``` r
TensorType(dtype, shape)
```

## Arguments

- dtype:

  ([`DataType`](https://rdrr.io/pkg/xlamisc/man/DataType.html))

- shape:

  ([`Shape`](https://r-xla.github.io/stablehlo/dev/reference/Shape.md))

## Value

`TensorType`
