# OpInputAttr

Base class for operation input attributes.

## Usage

``` r
OpInputAttr(name, value, dtype)
```

## Arguments

- name:

  (`character(1)`)  
  The name of the attribute.

- value:

  (any)  
  The value of the attribute.

- dtype:

  ([`DataType`](https://rdrr.io/pkg/xlamisc/man/DataType.html))  
  The dtype of the attribute.

## Value

(`OpInputAttr`)
