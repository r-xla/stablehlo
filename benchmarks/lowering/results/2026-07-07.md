# Lowering benchmark: main vs perf-lean-ir

Micro-benchmark of the two hot phases of producing an MLIR program with the
`stablehlo` builder: **build** (op emission + type inference) and **repr**
(rendering to MLIR text). Script: [`../lowering.R`](../lowering.R).

## Environment

- Date: 2026-07-07
- Machine: Apple M1 Pro (aarch64-apple-darwin20)
- R 4.5.3, bench 1.1.4
- 20 iterations per measurement; median reported

## Package versions

| label | branch | commit | state |
|---|---|---|---|
| before | main | `311a0022` | clean |
| after | perf-lean-ir | `5e28ef22` | clean |

## Results

`before_ms` / `after_ms` are median wall-clock milliseconds.

| graph | size | phase | before_ms | after_ms | speedup |
|---|---|---|---|---|---|
| chain | 200 | build | 83.6 | 11.9 | 7.0x |
| chain | 200 | repr | 32.5 | 5.6 | 5.8x |
| chain | 1000 | build | 438.7 | 70.6 | 6.2x |
| chain | 1000 | repr | 171.8 | 39.9 | 4.3x |
| chain | 5000 | build | 2011.8 | 431.3 | 4.7x |
| chain | 5000 | repr | 705.1 | 182.2 | 3.9x |
| fan | 200 | build | 155.0 | 29.2 | 5.3x |
| fan | 200 | repr | 66.1 | 13.3 | 5.0x |
| fan | 1000 | build | 769.7 | 189.9 | 4.1x |
| fan | 1000 | repr | 286.0 | 57.3 | 5.0x |
| fan | 5000 | build | 4353.7 | 825.7 | 5.3x |
| fan | 5000 | repr | 1483.2 | 361.2 | 4.1x |

Overall the descriptor-based lazy-rendering builder is ~3.9x-7.0x faster
across both phases. Both versions scale roughly linearly in op count, so the
win is per-op constant-factor overhead rather than an asymptotic change.
